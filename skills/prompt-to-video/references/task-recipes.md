# 按任务丰富提示词 / Task recipes

这些简报是本项目新编写的起点，不是已渲染作品，也不是质量保证。把占位内容换成用户真实资料，再按完整流程制作。/ These newly authored briefs are starting points, not rendered films or quality guarantees. Replace placeholders with real user material, then run the production workflow.

## 产品发布 / Product launch

**中文**：为 [产品] 做 20 秒介绍，观众是 [目标用户]，观众看完应理解 [核心价值]。依据 [真实界面与功能文档]，只展示确实存在的功能。0–3 秒用一个真实痛点开场；3–8 秒演示捕获；8–13 秒演示整理；13–17 秒展示执行结果；17–20 秒给出产品名和真实链接。统一界面字体，奶油白与炭黑，一个橘色强调色。指针点击之后才出现界面反馈，匹配转场保留同一任务卡片。先检查文字与真实流程，再交付配乐 MP4、预览、源码与素材清单。

**English**: Make a 20-second introduction to [product] for [audience], communicating [core value]. Use [real UI and feature docs]; show only actual features. 0–3s: a real problem; 3–8s: capture; 8–13s: organize; 13–17s: show the outcome; 17–20s: product name and real URL. Share one UI type system, cream/charcoal and an orange accent. Clicks precede feedback; match cuts preserve the same task card. Inspect text and the actual flow before delivering a scored MP4, preview, source and asset list.

## 算法解释 / Algorithm explainer

**中文**：用 25 秒解释 [算法]，面向 [有何基础的观众]。先核对 [权威定义]，明确演示输入、状态、规则和输出。一个固定图解，3–4 个有代表性的事件，先展示正常情况，再展示边界或失败情况。把每个事件与图形变化、计数、音效绑定到同一时间；拖动时间线也应得到相同结果。不要用装饰粒子代替因果。图示是简化模型时注明。交付状态检查、关键帧和带轻配乐成片。

**English**: Explain [algorithm] in 25 seconds to [audience and prior knowledge]. Verify [authoritative definition]; specify demonstration inputs, state, rules and outputs. Use a stable diagram and 3–4 representative events, showing the normal case before a boundary or failure. Bind events, geometry, counters and cues to one timeline, including identical results after seeking. Show causality through the diagram; label simplifications. Deliver model checks, keyframes and a lightly scored film.

## 数据叙事 / Data story

**中文**：将 [数据文件和来源] 做成 30 秒视频，回答 [具体问题]。先检查单位、日期范围、缺失值和比例尺。0–5 秒给问题与单位；5–15 秒画出主要变化；15–24 秒标记两个由数据支持的观察；24–30 秒给结论与出处。使用真实比例尺，不通过动态截断轴放大差异。数据决定线条位置与运动，不把相关性说成因果。长说明移到字幕或附注，关键数字留足阅读时间。

**English**: Turn [dataset and source] into a 30-second film answering [specific question]. Check units, date range, missing values and scales first. 0–5s: question and units; 5–15s: reveal the main change; 15–24s: highlight two supported observations; 24–30s: conclusion and source. Use honest scales without animated axis truncation to exaggerate differences. Data determines geometry; distinguish correlation from causation. Move long explanations into captions or notes and allow time to read key figures.

## 文章转视频 / Article to video

**中文**：根据 [文章链接或全文] 做 45 秒编辑式解说。提炼一个主张、三个有出处的支撑点和一个限制；保留作者与日期，不添加没有证据的引文。以材料特写、时间线、地图或对比图表达每个支撑点。先保存事实表，再写分镜与旁白。需要配音时用可用 TTS 或用户音轨；没有配音工具则明确说明并制作字幕版本。配乐只衬托内容。

**English**: Adapt [article] into a 45-second editorial explainer. Extract one claim, three sourced supporting points and one limitation; retain author/date and avoid fabricated quotations. Use material close-ups, timelines, maps or comparisons for the evidence. Save a fact sheet before the storyboard and narration. Use available TTS or supplied speech; if unavailable, explicitly deliver a captioned version. Keep music subordinate to the content.

## 口播白板 / Voice-led whiteboard

**中文**：把 [音频] 变成跟随口播的白板动画，时长由真实音轨决定。先按句子保存时间点，再给每句话安排一个可理解的笔画或图形变化。三种颜色以内，先画对象再画关系；文字避免逐字追赶语速。重要概念说到时才展开，保留有目的的停顿。原音轨不变，配乐轻，检查对白清晰度与关键声画时点。

**English**: Turn [audio] into a narration-led whiteboard film using the actual track duration. Mark sentence timestamps, then pair each with a clear stroke or diagram change. Use at most three colors; draw objects before relationships. Do not race the speaker with word-by-word text. Reveal ideas when spoken and retain purposeful holds. Preserve the supplied speech, keep music quiet and inspect intelligibility and key synchronization points.
