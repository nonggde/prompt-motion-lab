# 风格方向 / Style directions

这些是新编写的制作方向，不是已经实现并验证的八个模板。选择与内容最相符的一种，再通过样片验证。/ These newly authored directions are not eight prebuilt, tested templates. Choose for the content, then validate through a sample.

| 方向 / Direction | 适合 / Best for | 视觉与运动 / Visuals and motion | 检查重点 / Inspect |
|---|---|---|---|
| 白板 / Whiteboard | 口播、教程、流程 / narration, tutorials, processes | 纸面、有限色彩、笔画随语言展开；线条揭幕有先后 / paper, sparse palette, strokes revealed in narration order | 画面不抢口播、线条不是全屏同时出现 / voice leads, no all-at-once reveals |
| 编辑式叙事 / Editorial | 历史、时事、文章 / history, news, articles | 真实材料、局部高亮、地图与图表、明确来源 / sourced material, focused highlights, maps, charts | 不编造引文与年份，区分图表和装饰 / no fabricated quotes or dates |
| 几何科普 / Geometric explainer | 数学、算法、AI 概念 / math, algorithms, AI | 简化几何、因果变化、直标；参数操作改变结果 / simple geometry, causal motion, direct labels | 模型语义正确，示意有标记 / correct semantics, schematics labeled |
| 产品界面 / Product UI | 软件介绍、操作教程 / launches, software walkthroughs | 真实界面状态、指针、匹配转场、克制弹簧 / real UI states, cursor, match cuts, restrained springs | 不伪造功能，点击与界面反馈同步 / honest features, synchronized feedback |
| 数据叙事 / Data story | 财经、业务指标 / finance, metrics | 共用比例尺、数据决定运动、随讲解显现 / shared scales, data-driven movement, paced reveals | 来源、单位、时间、轴域准确 / source, units, dates and domains |
| 纸艺故事 / Paper story | 人物、情绪、文化 / characters, mood, culture | 层叠剪纸、受控视差、人物与物体互动 / layered paper, restrained parallax, character interaction | 剪影清晰、前后层不冲突 / clear silhouettes and depth |
| 动态字体 / Kinetic type | 短开场、品牌节奏 / short intros, identity | 少词、大字、遮罩、字形匹配；节奏驱动层级 / few words, strong type, masks, matched forms | 可读性、留白、文字不重叠 / readability, space, no text collisions |
| 风格旅程 / Style journey | 艺术叙事、连续穿越 / art-led continuous journeys | 角色动作与构图保持，场景笔触和配色变化 / stable action/composition, changing mark-making and palette | 真正内部动作，风格转场有连续性 / in-shot action and coherent transitions |

## 把风格写成可执行描述 / Make style actionable

“有某某频道的感觉”不足以开工。拆成：线条粗细、字体、色彩数量、平面或空间、纹理来源、镜头运动、角色动作、声音与留白。人物写实需求优先用已提供素材或可用的图像工具；几何化人物是另一种方向，应告诉用户选择结果。

A channel name alone is insufficient. Specify stroke weight, type, color count, flatness/depth, texture source, camera movement, character action, sound and holds. For realistic characters, use provided assets or available image tools; disclose a geometric-character choice rather than implying realism.

## 本项目已验证的两个方向 / Two validated directions here

- **FORM & FLOW**：动态字体 + 真实三维点坐标投影，四镜头、炭黑/奶油白/橘色、120 BPM。适合 15 秒动效作品；不是流体物理模拟。/ Kinetic type and projected 3D points, four shots, charcoal/cream/orange, 120 BPM. A 15-second reel, not a fluid simulation.
- **Token bucket**：资源变化驱动可视化，固定请求事件表、连续补充、精确消耗。适合算法解释；请求流是演示数据。/ Resource-driven geometry, fixed request events, continuous refill and exact consumption. An algorithm explainer using demonstration traffic.
