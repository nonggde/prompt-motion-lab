# 从需求到成片

[English](workflow.en.md) · [返回项目](../README.md)

核心不是找到一句万能提示词，而是让内容、视觉与时间线互相配合。这里把来源研究整理成一套可以实施、检查、修改的流程。

## 1. 把用户需求变成简报

记录目标、观众、真实内容、时长、画幅、语言、素材与声音。涉及事实的内容先确认来源；涉及产品的内容用真实功能与界面。非关键缺项可自行选择并说明，例如 15 秒、16:9、一个强调色。需要用户决策的事实或付费资源，才提出具体问题。

把「做一条很酷的视频」改成：

> 给独立开发者介绍任务管理工具，20 秒。表达“捕获 → 归类 → 今日执行”，每个镜头只讲一个操作。1920×1080，中英字幕；奶油白背景、炭黑正文、橘色强调。不使用虚构用户评价。交付 MP4、预览、源码与分镜。

在 [提示词手册](../skills/prompt-to-video/references/prompt-playbook.md) 中使用结构化模板。来源库保留原作者文字；不要把部分原帖描述误当成完整制作指令。

## 2. 选服务内容的视觉语言

图解算法适合明确的资源、事件与状态；产品介绍适合真实界面；艺术短片适合统一形状、材质与运动规则。参考片优先拆出配色、字体比例、画面密度、镜头时间与动作关系，再写成可实现的要求。

[八种风格方向](../skills/prompt-to-video/references/style-directions.md) 是设计建议，不代表八套现成模板。当前内置示例采用 Canvas 2D；环面是三维坐标投影到二维画布，不是已集成 Three.js 场景。

## 3. 用时间表安排镜头与声音

| 时间 | 内容 | 内部动作 | 转场 / 声音 |
| --- | --- | --- | --- |
| 0–3.5 秒 | IDEAS TAKE SHAPE | 字体从遮罩中进入，圆形长大 | 合成节拍；圆形擦拭 |
| 3.5–8 秒 | FORM INTO FLOW | 5,720 点构成的环面旋转、变形 | 同一节拍；圆形擦拭 |
| 8–11.5 秒 | MAKE IT MOVE | 大字揭幕，星形旋转与脉动 | 反色画面；圆形擦拭 |
| 11.5–15 秒 | FORM & FLOW | 字体收束，环形元素缓慢转动 | 最后收尾，配乐淡出 |

这是 FORM & FLOW 的实际分镜。不要把固定 120 BPM 和快切套用到所有内容。口播视频先按语音段落安排镜头，留足阅读时间。检查画面内部动作是否传递含义，而不仅是镜头间有转场。

令牌桶示例则采用一个稳定图解：0–4 秒说明容量，4–8 秒出现突发请求，8–12 秒强调拒绝条件，12–16 秒解释连续补充，16–20 秒收束。旁路计数和事件来自同一模型，拖动时间线也会重新计算。

## 4. 写可以定位到任意时刻的画面

每帧是时间 `t` 和固定配置的函数。不要在渲染中累积上一帧位置、调用未固定种子的随机数或等待实时网络。物理模拟需要预计算轨迹，或从固定初态重放。浏览器播放用时钟，导出用 `i / fps` 的精确时间。

自定义场景参考 [场景示例](../examples/custom-scene.cjs) 与 [渲染接口](../skills/prompt-to-video/references/render-contract.md)。内置播放器只加载两支示例；新场景需要给同一绘制函数连接独立预览。文字优先做可读性检查，字体与素材完成加载后再捕获。

## 5. 先看图，再看短样片

```sh
npm ci
npm test
npm run render -- --scene examples/custom-scene.cjs --output media/my-film.mp4 --stills-only
```

打开生成的分镜图，检查字形、留白、重叠、主次和逻辑。抽帧图无法证明运动连续性，还要查看转场前后与短样片。检查发现问题后定向修改，例如“圆形右移，避免与标题重叠”，比“更高级”更可执行。

`--duration 2` 可以先导出开头两秒；任意镜头的短样片应在场景代码里为 `t` 加固定偏移。默认分镜是 16 个均匀时间点，并不会自动覆盖每个切镜边界。

## 6. 声音与画面共享事件

本项目的配乐和提示音通过代码合成。令牌桶提示音按事件的通过/拒绝状态决定，预览改变容量或速度时声音也随之变化。下载的 MP4 使用默认配置：容量 4、每秒补充 1 个令牌。

有口播就使用用户语音或可用 TTS；合成配乐不能替代配音。当前项目没有绑定 TTS 或云视频服务。内置导出使用单遍 -16 LUFS / -1.5 dBTP 目标，不把目标值当成成片响度测量结果。

## 7. 导出并验证真实文件

```sh
npm run render -- --mode reel
npm run render -- --mode bucket
npm run check:media
npm run build
npx playwright install chromium
npm run test:browser
```

检查两支内置影片完整解码、1920×1080、60fps、15/20 秒和 AAC 音轨。检查页面双语、筛选、播放、参数和离线构建。新片需要单独验证自身期望尺寸与时长，不能用内置示例检查结果代替。

交付成片、预览、源码、简报与署名；说明实际工具和未解决限制。安装 [AI Skill](../skills/prompt-to-video/SKILL.md) 可以让具备代码执行和文件访问能力的 AI 使用这个流程。
